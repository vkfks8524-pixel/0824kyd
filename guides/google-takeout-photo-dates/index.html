구글 테이크아웃 사진 날짜가 바뀌었을 때: JSON 파일을 지우면 안 되는 이유

구글 포토를 내려받았더니 날짜가 모두 오늘로 보일 때 확인할 순서입니다. 날짜의 세 종류를 구분하고 JSON 파일을 보관하세요.

날짜는 하나가 아니다

날짜어디에 있나의미
파일 날짜탐색기의 만든 날짜·수정한 날짜이 컴퓨터에 파일이 생긴 시각일 수 있음
촬영 시각사진 안의 EXIF카메라가 기록한 시각
추가 정보함께 받은 JSON서비스에 저장돼 있던 설명·시각 등

압축을 풀면 파일 날짜가 오늘로 바뀌는 일은 흔합니다. 이것만 보고 촬영일이 사라졌다고 판단하면 안 됩니다.

먼저 사진 세 장만 확인하기

  1. 받은 압축 파일은 손대지 말고 따로 보관합니다.
  2. 오래된 사진, 화면 캡처, 편집한 사진을 한 장씩 고릅니다.
  3. 사진 정보 확인 도구에 넣어 '촬영 시각'이 보이는지 봅니다.
  4. 보이면 그 사진은 날짜를 고칠 필요가 없습니다. 사진 앱으로 가져오면 촬영 시각으로 정렬되는지 확인합니다.
  5. 보이지 않으면 같은 이름의 JSON을 메모장으로 열어 내용을 확인합니다.

세 장의 탐색기 날짜가 모두 같아도 조치는 다릅니다. 전체에 같은 날짜를 덮어쓰는 명령을 먼저 실행하면 이 구분이 사라집니다.

테이크아웃에서 알아둘 것

  • 구글 데이터를 내려받아도 구글 서버의 데이터가 삭제되지는 않습니다.
  • 정한 크기보다 데이터가 크면 보관 파일이 여러 개로 나뉩니다. 모든 조각을 받았는지 확인하세요.
  • 요청한 뒤 만들어지기 전에 바꾼 내용은 들어가지 않을 수 있습니다.
  • 내려받은 뒤 바로 원본을 지우지 말고, 조각이 모두 열리는지 먼저 확인하세요.

일괄 수정을 멈춰야 할 때

  • 하나의 사진에 JSON 후보가 여러 개일 때
  • 압축을 푸는 중 오류가 있었을 때
  • 프로그램이 원본을 직접 덮어쓴다고 할 때
  • 시간대 때문에 9시간씩 차이 나는 것처럼 보이지만 확인하지 못했을 때

자주 묻는 질문

JSON 파일이 사진보다 많은데 지워도 되나요?

사진이 잘 열린다고 JSON이 필요 없는 것은 아닙니다. 설명이나 서비스에 저장된 시각을 나중에 쓸 수 있습니다. 용량이 작으므로, 원본 압축 파일을 보관한 상태에서 보기용 사본만 따로 정리하는 방법이 안전합니다.

촬영 시각이 9시간 차이 납니다

한국 시각과 세계 표준시의 차이와 같습니다. JSON은 세계 표준시로, 사진 안의 시각은 현지 시각으로 기록된 경우에 이런 차이가 보일 수 있습니다. 하지만 해외에서 찍은 사진이 섞여 있다면 모두 9시간을 더하는 것은 틀릴 수 있습니다. 장소를 아는 사진 몇 장으로 먼저 확인하세요.

압축을 합칠 때 같은 이름이 있다고 나옵니다

덮어쓰지 마세요. 여러 조각에 같은 이름의 다른 사진이 있을 수 있습니다. 조각마다 별도 폴더에 풀고, 중복 파일 찾기로 정말 같은 파일인지 확인한 뒤 합치세요.

일괄 변환 프로그램을 써도 되나요?

원본을 따로 둔 작업용 사본에만 쓰세요. 먼저 세 장으로 시험해 날짜, 설명, 한글 이름이 제대로 반영되는지 보고, 프로그램이 원본을 덮어쓰는지 확인해야 합니다. 결과를 설명할 수 없는 프로그램에 전체 사진을 맡기지 마세요.

정리가 끝나면 무엇을 남겨야 하나요?

내려받은 압축 파일 전체, 정리한 사진 폴더, 어떤 기준으로 정리했는지 적은 메모를 남기세요. 구글에서 사진을 지우는 일은 별개의 결정입니다. 압축 파일을 다른 장치에서 풀어 보고 사진과 동영상이 열리는 것을 확인한 뒤 판단하세요.
