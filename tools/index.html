What “local” means here

The file checker reads only two files you choose. The other tools use typed numbers or checkboxes. Tool code does not upload or persist these inputs. Loading a website still makes hosting requests; read the privacy details.

The tools are intentionally limited. For large archives, use an appropriate batch verification and backup system. Begin with the recovery drill before deciding what evidence you need.
