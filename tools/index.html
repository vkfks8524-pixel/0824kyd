업로드하지 않는다는 뜻

도구를 실행하면 선택한 파일을 브라우저가 읽어 화면 안에서 계산합니다. 도구 페이지에는 외부 연결을 막는 보안 정책이 있어 페이지의 코드가 파일을 다른 곳으로 보낼 수 없습니다. 페이지를 연 뒤 인터넷을 끊어도 대부분의 기능이 작동합니다.

어떤 도구부터 써야 할까요

  • 사진을 제출하거나 보내야 할 때: 용량 줄이기, 증명사진 크기
  • 사진을 공개해야 할 때: 위치정보 확인
  • 휴대폰이나 PC를 비우고 싶을 때: 백업 자가점검, 폴더 비교
  • 저장공간이 부족할 때: 중복 찾기, 용량 계산
