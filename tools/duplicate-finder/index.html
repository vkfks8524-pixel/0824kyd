중복 파일 찾기

폴더에서 내용까지 완전히 같은 사진과 동영상을 찾아 목록으로 만듭니다.

폴더를 선택해 주세요.

같은 파일 묶음

선택한 파일은 이 화면 안에서만 읽으며 서버로 전송되지 않습니다.

판단 방법

크기가 같은 파일끼리 묶은 뒤 4MB씩 읽어 모든 바이트를 비교합니다. 이름, 날짜, 썸네일로 판단하지 않습니다. 파일 10개 시험에서 이름만 다른 파일은 찾아내고, 크기만 같은 파일은 구분했습니다.

결과를 정리하는 순서

  1. CSV 목록을 저장합니다.
  2. 묶음마다 남길 파일 하나를 고르고 직접 열어 봅니다.
  3. 나머지를 탐색기에서 휴지통으로 옮깁니다.
  4. 며칠 뒤 문제가 없으면 휴지통을 비웁니다.

알아둘 점

  • 백업 폴더와 원본 폴더를 함께 고르면 정상적인 백업도 중복으로 나옵니다. 백업을 지우지 마세요.
  • 축소본이나 편집본처럼 비슷한 사진은 찾지 않습니다.
  • 브라우저가 업로드라고 표시해도 실제로는 이 페이지가 읽을 권한을 얻는 것입니다. 외부 전송은 보안 정책으로 막혀 있습니다.
