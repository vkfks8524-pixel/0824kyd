중요한 이메일·클라우드 계정을 기준으로 현재 완료한 보안 항목을 체크하세요. 이메일 주소, 비밀번호, 전화번호나 계정 이름은 입력하지 않으며 체크 상태도 저장하지 않습니다.

완료한 항목 선택

중요한 계정 하나를 떠올리고 실제 설정을 확인한 항목만 선택하세요.

점검 결과

모든 기본 항목을 선택했습니다. 정기적으로 최근 활동과 복구 수단을 다시 확인하세요.

먼저 보완할 항목

    점수보다 미완료 항목이 중요합니다

    이 점수는 실제 계정이나 침해 여부를 검사하지 않습니다. 각 항목에 단순한 가중치를 적용해 점검 순서를 보여주는 계획 도구입니다. 100점을 받아도 이미 비밀번호가 유출되었거나 복구 이메일이 탈취된 상황까지 판단할 수 없습니다.

    반대로 낮은 점수는 계정이 현재 해킹되었다는 뜻이 아닙니다. 이메일처럼 다른 서비스의 비밀번호 재설정에 사용되는 핵심 계정부터 보완하세요. 고유 비밀번호와 2단계 인증은 가장 큰 비중으로 계산되며, 복구 수단과 로그인 기기 확인이 뒤를 잇습니다.

    우선순위 1: 고유 비밀번호와 패스키

    여러 사이트에서 같은 비밀번호를 사용하면 한 곳의 정보 유출이 다른 계정의 로그인 시도로 이어질 수 있습니다. 사이트마다 다른 긴 비밀번호를 사용하고 기억하기 어렵다면 신뢰할 수 있는 비밀번호 관리자를 이용합니다. 패스키를 지원하는 서비스에서는 피싱 페이지에 비밀번호를 입력할 가능성을 줄이는 선택지가 될 수 있습니다.

    우선순위 2: 2단계 인증과 복구 수단

    2단계 인증은 비밀번호 외에 한 번 더 본인임을 확인합니다. 인증 앱, 기기 알림, 보안 키와 패스키 등 서비스가 지원하는 방법을 비교하세요. 휴대전화를 잃어버렸을 때를 대비해 예비 인증 방법과 복구 코드를 준비하되, 비밀번호와 같은 장소에 보관하지 않습니다.

    복구 전화번호와 이메일은 계정을 되찾는 열쇠가 될 수 있습니다. 오래된 회사 이메일이나 사용하지 않는 번호가 남아 있다면 현재 본인이 통제하는 정보로 갱신합니다. 복구 정보를 변경했다는 알림이 왔는데 본인이 한 행동이 아니라면 즉시 계정의 공식 보안 페이지에서 활동을 확인하세요.

    우선순위 3: 로그인 기기와 보안 활동

    비밀번호를 바꾼 뒤에도 기존 로그인 세션이 남을 수 있습니다. 최근 보안 활동과 로그인된 기기 목록에서 시간, 위치, 기기 종류를 확인하고 모르는 항목을 로그아웃합니다. 이메일 전달 규칙, 연결된 앱 권한과 결제 수단처럼 계정 내부에서 바뀔 수 있는 설정도 함께 확인하세요.

    도구가 요구하지 않는 정보

    계정 이름, 이메일 주소, 비밀번호, 복구 전화번호, 인증번호를 입력할 필요가 없습니다. 이러한 정보를 요구하는 자가점검 사이트는 이용하지 않는 편이 안전합니다. 실제 설정을 확인하려면 문자나 이메일의 링크가 아니라 서비스 공식 앱이나 주소를 직접 이용하세요.

    결과의 한계와 침해 의심 시 조치

    모르는 로그인, 본인이 요청하지 않은 인증번호, 변경된 복구 정보나 결제가 보인다면 자가점검보다 계정 복구와 피해 신고가 먼저입니다. 안전한 기기에서 공식 계정 페이지에 접속하고 서비스 제공자의 “계정이 도용됨” 절차를 이용하세요.

    기본 설정 방법은 구글 계정 보안 점검, 비밀번호 관리 시작은 비밀번호 관리자를 처음 쓸 때, 브라우저 저장 여부는 브라우저 비밀번호 저장 기능 사용 기준을 참고하세요.
