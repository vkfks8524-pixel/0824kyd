    Why inspect the final extension first?

    A Windows filename commonly includes a name and extension, used as a clue for app association and icons. For example, holiday.jpg has the final extension .jpg, while holiday.jpg.exe has the final extension .exe. Hiding extensions can make the second name resemble a photo.

    Microsoft explains that renaming an extension does not convert file contents. Renaming a suspicious file to .txt or .jpg does not make it safe. Inspect its source, publisher information and operating-system warnings without executing it.

    What are text-direction controls?

    Some Unicode characters change visible text order. Misuse can make the ending look different from the underlying final extension. This tool flags representative direction controls; it cannot reproduce every operating system or app’s rendering.

    Show real extensions in Windows

    In Windows 11 File Explorer, select View → Show → File name extensions. In older Windows 10 File Explorer, use the View tab → File name extensions checkbox. Do not bypass a download warning because the extension looks familiar. Legacy Office formats such as .doc and .xls can contain macros.

    Analysis limits

    This does not inspect contents, hashes, signatures or malware. Legitimate apps use executable endings, and harmful content can be inside a PDF or document. Common media extension means a different filename category, not safety.

    If you already executed the file or installed a program, inspecting the name is insufficient. Stop network use and inspect operating-system security and account activity. See why to show Windows file extensions and Chrome download-warning decisions for the detailed decision process.
