저장공간 정리 목표 계산기

도구 및 설명 최종 검토: 2026년 8월 23일

스마트폰이나 컴퓨터의 전체 저장용량과 현재 남은 용량을 입력하면 선택한 목표까지 몇 GB를 정리해야 하는지 계산합니다. 파일을 읽거나 삭제하지 않으며 입력값도 저장하지 않습니다.

현재 저장공간 입력

기기 설정에 표시된 전체 용량을 GB 단위로 입력하세요.

제조사마다 권장 기준이 다르므로 이 비율은 계획용 목표입니다.

권장 확인 순서

    정리 목표를 먼저 계산해야 하는 이유

    “용량이 부족하다”는 알림만 보고 사진이나 문서를 무작정 지우면 필요한 자료를 잃기 쉽습니다. 목표가 3GB인지 30GB인지에 따라 적절한 방법이 달라집니다. 작은 목표라면 휴지통과 다운로드 폴더만 확인해도 충분하지만, 큰 목표라면 사진·동영상 백업과 사용하지 않는 앱 정리가 필요합니다.

    계산기는 전체 용량에 목표 비율을 곱해 필요한 여유 공간을 구하고 현재 남은 공간과의 차이를 정리 목표로 표시합니다. 제조사, 운영체제, 업데이트 크기와 사용 패턴이 다르므로 결과는 고정된 성능 보장 기준이 아니라 안전하게 계획을 세우기 위한 숫자입니다.

    저장용량과 메모리는 다릅니다

    저장용량은 사진, 동영상, 앱과 문서를 보관하는 공간입니다. 메모리 또는 RAM은 실행 중인 앱과 운영체제가 사용하는 작업 공간입니다. 앱이 자주 종료되거나 여러 앱을 동시에 쓰기 어려운 문제를 저장공간 정리만으로 해결할 수는 없습니다.

    반대로 저장공간이 거의 가득 차면 새 앱과 업데이트를 설치하기 어렵고 사진 촬영이나 파일 저장이 실패할 수 있습니다. Android 공식 안내는 설정의 저장용량 메뉴에서 카테고리별 사용량을 확인하고, 백업된 사진·동영상이나 사용하지 않는 항목을 선택해 공간을 확보하도록 안내합니다.

    안전한 정리 우선순위

    1. 휴지통과 다운로드: 다시 받을 수 있는 설치 파일, 오래된 PDF와 이미 삭제한 파일의 휴지통부터 확인합니다.
    2. 오프라인 콘텐츠: 음악·영상 앱에 임시로 저장한 다운로드는 계정에서 다시 받을 수 있는지 확인한 뒤 정리합니다.
    3. 사용하지 않는 앱: 앱 내부 데이터와 로그인 방법을 확인하고 제거합니다. 앱 캐시와 앱 데이터 삭제는 서로 다릅니다.
    4. 메신저 미디어: 대화방의 동영상과 중복 파일을 용량순으로 확인합니다. 중요한 대화 자료는 별도로 백업합니다.
    5. 사진과 동영상: 클라우드의 “백업 완료” 표시만 보지 말고 다른 기기나 웹에서 실제로 열리는지 확인한 뒤 정리합니다.

    클라우드 용량과 기기 용량 구분하기

    Google Drive나 Google 포토의 클라우드 공간이 부족한 것과 스마트폰 내부 공간이 부족한 것은 다른 문제입니다. 기기에서 파일을 지우면 동기화 설정에 따라 클라우드에서도 삭제될 수 있고, 반대로 클라우드 파일만 정리해도 기기 공간이 바로 늘지 않을 수 있습니다. 삭제 버튼을 누르기 전에 동기화·백업 상태와 휴지통 보관 기간을 확인하세요.

    계산 결과의 한계

    실제 기기 파일 목록, 운영체제 예약 공간, SD 카드와 클라우드 상태를 읽지 않습니다. 입력한 전체 용량은 제조사 표기와 운영체제 표시가 조금 다를 수 있습니다. 계산 결과가 “추가 정리 불필요”여도 업데이트 오류나 손상된 앱처럼 다른 원인이 있을 수 있습니다.

    구체적인 삭제 순서는 스마트폰 저장 공간이 부족할 때 먼저 확인할 것, 사진 보호 방법은 스마트폰 사진 백업 기본 방법, 클라우드 공간은 클라우드 저장 공간 정리 우선순위를 참고하세요.
