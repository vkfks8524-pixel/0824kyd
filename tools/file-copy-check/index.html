Identical bytes do not prove a healthy photo, an authentic source or a complete backup. Different bytes can result from conversion or editing.
One precise question
“Are the selected contents exactly the same?” Names, timestamps and thumbnails do not decide the result. The tool compares every byte and independently displays SHA-256 fingerprints.
Compare unmodified originals when that is your preservation goal. A converted JPEG and an original HEIC will not match just because they show the same picture.

Try before selecting files
The demo compares abc with itself, then with abd. Both are three-byte text fixtures. No personal files are read during the demo.
Privacy boundary
Tool pages prohibit outbound connections from page scripts. The page has no ad script. The browser or operating system may download a cloud placeholder when you select it; choose already-local files if that matters. More privacy details.
For large videos
This is not a batch archive verifier. The browser digest API needs whole inputs in memory, so the 32 MiB limit is intentional. Do not cut or compress an original just to fit this tool.
Reproducible method
Equality is determined by direct byte comparison, not merely equal filenames, file sizes or hashes. Inspect the implementation and test cases. After a match, open the copied media separately in a trusted viewer; this page does not decode it.
