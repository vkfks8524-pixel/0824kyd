URL structure checker

Last tool and explanation review: September 6, 2026

Before opening a link from a message, QR code, email or PDF, inspect its actual host and less-visible structure. The address is analyzed only in this browser, not sent to KYD or an external reputation service.

Do not enter addresses containing passwords or authentication codes. Inputs are not sent over the network.

Items to review

    Compare examples before entering your address

    The buttons fill and analyze educational examples without visiting them. Compare hosts and findings: does @ mean the same thing in both addresses?

    The first example’s host is files.example.org and a user-information flag is shown. The second host is example.com; its path’s @ is not treated as user information. Four PDF-link comparisons and test criteria explain the differences further.

    javascript:, mailto: and inputs with spaces or backslashes are not supported. A bare domain is parsed with an assumed HTTPS prefix; this does not prove the actual connection is encrypted. When entering a port, include https:// or http://.

    What this tool inspects

    A URL has a protocol, host, port, path and query. Familiar service labels or senders do not determine the destination host. This tool shows those components separately and highlights the following structures.

    • Unencrypted HTTP format
    • Numeric IP or nonstandard port
    • Shortened URL hiding its final destination
    • Punycode representing an internationalized domain
    • @ User information that can obscure the destination
    • Many subdomain labels and encoded characters

    Reading the result

    HTTPS format encrypts transport between a device and a site. A phishing site can also use HTTPS; a lock does not authenticate the operator’s trustworthiness. Chrome guidance recommends inspecting the site name even with a secure-connection indicator.

    Punycode is a legitimate internationalized-domain technology, but lookalike characters can be misleading. If it appears, verify the operator independently; use your usual official app or saved address instead of signing in from an unexpected message.

    Shortened URLs have legitimate uses. Their problem for inspection is a hidden final destination. Verify unexpected payment, delivery, fine or obituary messages through another channel.

    What this tool cannot inspect

    It does not query current content, domain ownership, malware distribution or Safe Browsing lists. A new phishing site may have no structural flags; a legitimate work or development address may use a nonstandard port. Do not use the result as a safety verdict.

    Do not bypass a red or deceptive-site browser warning because of this tool’s result. If you already clicked or submitted information, use the response guide for a suspicious message link and act according to what you actually did.
