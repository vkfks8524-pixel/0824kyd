Windows screenshots: choose a region, window or saved full screen

By KYD Editorial · First published 2026-07-12 · Last editorial review 2026-10-05

English edition adapted on 2026-10-05. The original source-check date is retained below; this is not a fresh product or match investigation.

Windows includes capture tools without requiring another download. Choose the smallest useful area, then inspect the image before sharing it with support or posting it publicly.

Choose the capture for the task

NeedShortcut or toolWhat to check
Select part of the screenWindows + Shift + SChoose the area, then paste or save the capture
Save the full screenWindows + PrtScnLook in Pictures → Screenshots; keyboard behavior can vary
Copy the active windowAlt + PrtScnConfirm which window is active before pasting

Print Screen behavior can depend on Windows settings and the keyboard; it may copy the screen or open a capture interface. Some keyboards require an additional function key. Inspect the result rather than assuming that pressing a key created a saved file.

Use Snipping Tool for more control

Find Snipping Tool through Start. Select an available region, window or delay option that fits the situation. A delayed capture can help when a temporary menu must be visible. Use the tool’s save or copy controls and verify where the result went.

Keep enough error context

A useful report includes the error text and enough of the app or nearby controls to explain where it happened. Cropping too tightly can remove the clue; capturing the entire desktop can expose unrelated information. If a sequence matters, provide separate labeled screenshots for the starting location, error and action rather than one crowded image.

Check privacy around the edges

Inspect the browser address bar, account name, notifications, file paths, tabs, bookmarks, conversations and taskbar. Names and private folder labels can appear far from the error itself. Crop unnecessary material or fully cover sensitive details with an opaque block.

Reopen the actual sharing copy

Save and inspect the final exported image, not only the editing view. Ensure that you are sharing the redacted copy rather than the original. Use descriptive filenames with a date and non-sensitive issue label, and verify every image if you attach several. See the screenshot privacy checklist for codes, locations and hidden context.

Manage retained screenshots

Keep files only as long as needed and according to applicable organizational rules. On a shared computer, avoid leaving private captures on the desktop or in Downloads after the task. Useful documentation should show the problem without exposing unrelated people’s information.
