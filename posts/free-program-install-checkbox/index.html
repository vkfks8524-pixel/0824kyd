컴퓨터 안전

무료 프로그램 설치할 때 체크박스를 조심해야 하는 이유

작성: KYD 디지털 가이드 편집팀 · 게시 2026년 7월 13일 · 최종 검토 2026년 8월 22일 · 예상 읽기 시간: 8분

무료 프로그램을 설치할 때 다음 버튼만 계속 누르면 원하지 않는 프로그램이나 브라우저 확장이 함께 설치될 수 있습니다. 설치 과정의 체크박스와 선택지를 확인하는 습관이 중요합니다.

1. 빠른 설치보다 사용자 지정 설치 보기

설치 프로그램에는 빠른 설치와 사용자 지정 설치가 함께 표시되는 경우가 있습니다. 빠른 설치는 편하지만 제휴 프로그램까지 함께 선택되어 있을 수 있습니다.

가능하면 사용자 지정 또는 고급 설치를 눌러 어떤 항목이 포함되는지 확인합니다.

2. 제휴 프로그램 체크 해제하기

백신, 검색 도구, 브라우저 확장, 쇼핑 도우미 같은 항목이 기본 체크되어 있을 수 있습니다. 필요하지 않은 항목은 설치 전에 체크를 해제합니다.

프로그램 이름이 익숙하지 않다면 설치하지 않는 편이 안전합니다.

3. 시작 페이지와 검색 엔진 변경 주의

일부 설치 프로그램은 브라우저 시작 페이지나 기본 검색 엔진을 바꾸려고 합니다. 설치 화면에 작은 글씨로 표시되는 경우도 있으므로 체크박스를 자세히 봅니다.

설치 후 브라우저 첫 화면이 바뀌었다면 브라우저 설정에서 시작 페이지와 검색 엔진을 다시 확인합니다.

4. 공식 다운로드 경로 이용하기

검색 결과의 광고 링크나 자료실보다 공식 홈페이지에서 설치 파일을 받는 것이 안전합니다. 같은 프로그램이라도 배포 사이트에 따라 추가 설치 항목이 포함될 수 있습니다.

파일 이름과 개발사 이름, 버전을 확인하면 잘못된 설치 파일을 받을 가능성을 줄일 수 있습니다.

5. 설치 후 바로 확인할 것

설치가 끝난 뒤 시작 프로그램, 브라우저 확장, 바탕화면 바로가기, 제어판의 설치된 앱 목록을 확인합니다.

원하지 않는 프로그램이 보이면 바로 제거하고, 브라우저 설정도 원래대로 돌려놓습니다.

정리

무료 프로그램 설치에서 가장 중요한 것은 급하게 다음 버튼을 누르지 않는 것입니다. 사용자 지정 설치, 체크박스, 제휴 프로그램, 브라우저 설정 변경 여부를 확인하면 불필요한 설치를 줄일 수 있습니다.

체크박스를 봐야 하는 이유

무료 프로그램 설치 화면에는 사용자가 꼭 필요한 프로그램 외에 제휴 프로그램, 브라우저 확장, 검색엔진 변경, 시작 페이지 변경 같은 선택 항목이 함께 들어 있는 경우가 있습니다. 문제는 이 항목들이 작은 글씨로 표시되거나 기본 선택되어 있을 때가 있다는 점입니다.

설치 버튼을 빠르게 누르면 원하지 않는 프로그램이 함께 설치되고, 이후 컴퓨터가 느려지거나 브라우저에 광고가 늘어날 수 있습니다. 그래서 설치 화면에서는 다음 버튼보다 체크박스를 먼저 보는 습관이 필요합니다.

설치 화면에서 읽어야 할 문장

추천 설치, 빠른 설치, 제휴 서비스, 브라우저 보호, 검색 도우미, 시작 페이지 설정 같은 표현이 보이면 한 번 멈춰야 합니다. 이런 문구는 꼭 악성이라는 뜻은 아니지만 내가 원한 기능과 직접 관련이 없는 추가 설치일 수 있습니다.

가능하면 사용자 지정 설치나 고급 설치를 선택해 포함 항목을 확인합니다. 익숙하지 않은 프로그램 이름이 보이면 체크를 해제하고, 설치하려는 핵심 프로그램만 남기는 것이 안전합니다.

설치 후 점검

설치가 끝난 뒤에는 제어판 또는 Windows 설정의 설치된 앱 목록을 열어 방금 설치한 프로그램 외에 낯선 항목이 추가되었는지 봅니다. 브라우저 확장 프로그램 목록과 시작 페이지도 함께 확인합니다.

원치 않는 항목이 보인다면 바로 제거합니다. 그리고 다음 설치부터는 공식 사이트에서 파일을 받고, 설치 화면을 한 단계씩 읽는 방식으로 바꾸면 같은 문제가 반복될 가능성을 줄일 수 있습니다.

설치 전 멈춰야 하는 문구

무료 프로그램 설치 중 '추천', '제휴', '브라우저 보호', '검색 품질 향상', '필수 구성 요소' 같은 문구가 보이면 내용을 자세히 읽어야 합니다. 일부는 실제로 필요한 구성 요소일 수 있지만, 일부는 사용자가 원하지 않는 추가 프로그램일 수 있습니다.

체크박스가 이미 선택되어 있는 경우도 많습니다. 설치 화면을 빠르게 넘기면 동의한 것으로 처리될 수 있으므로, 다음 버튼을 누르기 전에 선택된 항목이 무엇인지 확인하는 습관이 중요합니다.

문제가 생긴 뒤 되돌리는 법

설치 후 브라우저 첫 화면이 바뀌었거나 광고 팝업이 늘었다면 최근 설치 앱 목록을 열어 날짜순으로 정렬합니다. 내가 설치한 프로그램과 같은 시간대에 들어온 낯선 항목을 찾으면 원인을 더 빨리 찾을 수 있습니다.

브라우저 확장 프로그램도 함께 확인합니다. 원하지 않는 확장 프로그램을 삭제하고 검색엔진과 시작 페이지를 원래대로 바꾼 뒤, 컴퓨터를 다시 시작해 같은 증상이 반복되는지 확인합니다.
