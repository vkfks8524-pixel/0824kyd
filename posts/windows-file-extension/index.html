파일 관리

Windows에서 파일 확장자를 표시해야 하는 이유와 설정 방법

작성: KYD 디지털 가이드 편집팀 · 게시 2026년 7월 12일 · 최종 검토 2026년 9월 6일

첨부파일 이름이 안내문.pdf처럼 보여도 마지막 확장자가 숨겨져 있을 수 있습니다. 이 글은 Windows에서 전체 이름을 확인하고, 그 이름으로 알 수 있는 것과 알 수 없는 것을 구분하는 안내입니다. 파일을 실행할 필요는 없습니다.

확장명 표시 · 파일명 비교 · 판단 한계 · 직접 연습

확장명을 켠 뒤 무엇이 달라졌는지 확인하기

Windows 11 파일 탐색기에서 보기 → 표시 → 파일 확장명을 켭니다. Windows 10의 기존 탐색기는 보기 탭 → 파일 확장명 체크박스를 사용합니다. 아래 메뉴 설명은 Microsoft 문서에 근거한 것이며, 이 글에 Windows 실제 화면 캡처를 제시한 것은 아닙니다.

  1. 출처를 아는 문서가 있는 폴더를 엽니다.
  2. 확장명 표시를 켜고 파일 이름 끝에 .pdf 또는 .docx가 보이는지 확인합니다.
  3. 이름 열이 좁아 끝이 잘리면 열 너비를 늘리거나 파일을 한 번 선택해 전체 이름을 확인합니다. 더블클릭해 열지 않습니다.
  4. 받은 파일은 아이콘과 함께 마지막 확장자, 보낸 사람, 원래 요청한 파일 종류를 대조합니다.

확장명 표시는 파일을 변환하거나 보안 검사하는 기능이 아닙니다. 이름이 정확히 보이게 하는 설정입니다. 바로가기 같은 일부 특수 형식은 이름 표시만으로 확인하기 어려울 수 있으므로 속성의 파일 종류와 대상도 확인해야 합니다.

비슷해 보이는 이름 여섯 개를 비교하면

다음은 설명을 위해 만든 파일명입니다. 실제 첨부파일이나 악성 파일을 배포하지 않습니다.

파일명에서 읽을 단서와 다음 행동
전체 이름이름에서 알 수 있는 것다음 확인
안내문.pdfPDF 확장자로 표시됨내용이 실제 PDF인지, 요청한 발신자의 문서인지까지 보장하지 않음
안내문.pdf.exe마지막은 .exe, 문서처럼 보이는 중간 이름문서 요청에 실행 파일이 왔으므로 열지 않고 발신자에게 재확인
회의록.최종.docx이름에 점이 있지만 마지막은 .docx점이 여러 개라는 이유만으로 악성으로 단정하지 않음
예산.xlsm매크로 사용 Excel 형식내용 사용·매크로 허용을 요구하면 업무상 필요한 기능인지 확인
자료.pdf.lnk바로가기 형식의 이름실제 대상이 문서인지 프로그램인지 별도로 확인
사진.jpg.끝이 점이라 입력 그대로는 확장자가 명확하지 않음앱별 이름 처리 차이가 있으므로 실제 탐색기 이름을 다시 확인

확장자·아이콘·내용·서명은 다른 정보입니다

확장자는 운영체제가 파일을 여는 앱을 정할 때 쓰는 단서입니다. 아이콘 역시 연결 프로그램이나 파일 설정의 영향을 받습니다. 둘 다 바꿀 수 있으므로 “확장자가 실제 파일 형식을 증명한다”는 설명은 정확하지 않습니다. PDF라는 이름의 파일 내부가 전혀 다른 데이터일 수 있습니다.

디지털 서명은 이름보다 많은 정보를 제공할 수 있지만 서명이 있다는 이유만으로 실행해도 된다는 뜻은 아닙니다. 서명 대상과 게시자, 배포 경로, 브라우저 경고를 함께 봐야 합니다. 서명 탭이 없는 문서도 많으므로 탭이 없다는 이유만으로 악성으로 판단하지 않습니다.

또한 .doc, .xls, .ppt 같은 오래된 Office 형식도 매크로를 포함할 수 있습니다. .docm이 아니라는 이유로 보안 경고를 무시해서는 안 됩니다.

파일 없이 이름만 넣어 연습하기

파일명·확장자 확인 도구에서 위 표의 이름을 하나씩 입력하세요. 안내문.pdf.exe는 실행 형식과 이중 확장자 주의가, 회의록.최종.docx는 문서 형식과 여러 점에 관한 설명이 나오는지 비교합니다. 실제 파일을 업로드하거나 내려받을 필요가 없습니다.

이 연습은 문자열을 어떻게 읽는지 확인하는 것입니다. 탐색기 동작이나 악성코드 탐지 성능을 시험하는 것은 아닙니다. 도구 테스트의 입력·예상 결과와 검증 범위도 공개했습니다.

이름을 잘못 바꿨거나 이미 열었다면

직접 만든 파일의 확장자를 실수로 바꿨고 원래 이름을 정확히 안다면 원래 확장자로 되돌릴 수 있습니다. 원래 형식을 모르는 파일에 여러 확장자를 붙여 열어보는 방법은 쓰지 마세요. 발신자에게 원본을 다시 받거나 파일을 만든 앱의 내보내기 기능으로 변환합니다.

다운로드만 한 상황과 실행·설치까지 한 상황은 다릅니다. 이미 실행한 뒤 낯선 프로그램이 나타났다면 이름 검사로 해결하려 하지 말고 다운로드 경고 대응 안내를 확인하세요. 업무 기기는 담당자에게 파일명과 실행 시각을 알리고 조직 절차를 따릅니다.
