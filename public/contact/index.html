문의·오류 제보

잘못되거나 오래된 내용을 알려주세요

KYD 디지털 가이드는 공개 GitHub 저장소의 이슈 기능을 공식 제보 창구로 사용합니다. 글의 오류, 작동하지 않는 링크, 달라진 메뉴와 다뤄주길 바라는 주제를 남길 수 있습니다.

GitHub에서 새 제보 작성하기

공개 게시판입니다. 이름, 전화번호, 이메일 주소, 계정 ID, 주문번호, 인증 코드, 집 주소가 포함된 글이나 화면 캡처는 올리지 마세요.

제보에 포함하면 좋은 내용

  • 문제가 있는 KYD 글 주소
  • 현재 글에 적힌 설명과 실제로 달라진 부분
  • 기기 종류, 운영체제, 브라우저 또는 앱 버전
  • 가능하다면 해당 제조사나 서비스의 공식 도움말 주소

화면 캡처를 첨부할 때

문제와 관계없는 화면은 잘라내고 개인정보는 흐림 효과가 아닌 불투명한 색으로 완전히 가리는 것을 권합니다. QR코드와 바코드, 브라우저 주소창, 열린 탭, 작업 표시줄, 알림에도 개인 정보가 남을 수 있습니다. 자세한 점검 항목은 화면 캡처 개인정보 점검 가이드에서 확인할 수 있습니다.

처리 원칙

제보는 원문과 공식 자료를 대조한 뒤 반영 여부를 판단합니다. 재현할 수 없거나 근거를 확인하기 어려운 내용은 추가 정보를 요청하거나 반영하지 않을 수 있습니다. 광고·홍보·검색 순위 보장·유료 링크 삽입 요청은 받지 않습니다.

긴급한 계정·기기 문제

이 창구는 실시간 고객지원이나 계정 복구 창구가 아닙니다. 계정 탈취, 결제 피해, 기기 분실처럼 즉시 대응이 필요한 문제는 해당 서비스의 공식 고객지원과 경찰·금융기관 등 관계 기관에 직접 문의하세요. 비밀번호나 원격 접속 코드를 누구에게도 보내지 마세요.
