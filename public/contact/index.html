Report an issue

Contact & corrections

Found a wrong statement, a broken tool or an unclear safety boundary? A specific, reproducible report helps.

Open a public GitHub issue ↗

GitHub issues are public. Do not send photos, file contents, filenames that identify people, account details, passwords, recovery codes or private screenshots.

Include only what is needed

  1. The KYD page URL.
  2. The statement or behavior that appears wrong.
  3. For a tool, a harmless synthetic input and the expected result.
  4. Browser and operating-system versions, without device identifiers.
  5. An official source if service behavior changed.

For a file comparison bug, reproduce it with non-sensitive text fixtures if possible. Do not upload the original personal files. If a screenshot is essential, crop it and cover private details with an opaque block, then inspect the exported image.

This is not an emergency recovery service

We cannot sign in for you, recover a lost account or inspect a failing drive. Contact the relevant official provider or a suitable recovery professional. Never share authentication secrets with someone offering help in an issue thread.

English reports are welcome. GitHub requires its own account for submission and applies its own privacy terms.
