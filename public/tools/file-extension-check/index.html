확인할 항목

    마지막 확장자를 먼저 보는 이유

    Windows 파일 이름은 보통 이름과 확장자로 나뉘며 확장자는 파일을 여는 프로그램과 아이콘을 결정하는 단서가 됩니다. 예를 들어 여행사진.jpg의 최종 확장자는 .jpg지만, 여행사진.jpg.exe의 최종 확장자는 .exe입니다. 확장자 숨김이 켜져 있으면 두 번째 파일이 사진처럼 보일 수 있습니다.

    Microsoft는 파일 확장자를 바꿔도 실제 형식이 변환되는 것은 아니라고 설명합니다. 따라서 의심 파일의 이름을 .txt나 .jpg로 바꿨다고 안전해지는 것이 아닙니다. 실행하지 않은 상태에서 원래 출처와 디지털 서명, 운영체제 경고를 확인해야 합니다.

    도구가 구분하는 주요 형식

    분류예시확인할 점
    실행·설치.exe, .msi, .bat, .cmd, .ps1, .apk프로그램이나 명령을 실행할 수 있으므로 공식 배포처와 서명을 확인
    바로가기.lnk, .url, .scf문서처럼 보여도 다른 프로그램·명령·사이트를 열 수 있음
    매크로 문서.docm, .xlsm, .pptm자동화 코드가 포함될 수 있으므로 예상하지 않은 매크로 허용 금지
    압축·이미지.zip, .rar, .7z, .iso내부 파일의 최종 확장자를 다시 확인
    일반 문서·미디어.pdf, .docx, .jpg, .mp4확장자만으로 안전을 보장할 수 없으며 출처와 경고 확인

    문자 표시 방향 제어 기호란?

    일부 유니코드 문자는 화면에 보이는 문자 순서를 바꿀 수 있습니다. 이를 악용하면 실제 마지막 확장자와 화면에 보이는 문자열이 다르게 느껴질 수 있습니다. 이 도구는 대표적인 방향 제어 문자가 이름에 포함되었는지 표시하지만 모든 운영체제·앱의 렌더링 차이를 재현하지는 않습니다.

    Windows에서 실제 확장자 표시하기

    Windows 11과 10에서는 파일 탐색기를 열고 보기 → 표시 → 파일 확장명을 선택할 수 있습니다. 아이콘이나 미리보기보다 전체 파일 이름의 마지막 부분을 확인하세요. 다운로드 경고가 나타난 파일은 확장자가 익숙해 보여도 경고를 우회하지 않는 편이 안전합니다.

    분석 결과의 한계

    이 도구는 파일 내용, 해시, 전자서명이나 악성코드를 검사하지 않습니다. 정상 프로그램도 실행 확장자를 사용하고, 악성 콘텐츠가 PDF나 문서 파일 안에 포함될 수도 있습니다. “일반 미디어 형식” 결과는 파일이 안전하다는 뜻이 아니라 이름에서 확인되는 위험 범주가 다르다는 뜻입니다.

    파일을 이미 실행했거나 프로그램이 설치되었다면 파일명만 확인하는 것으로 충분하지 않습니다. 네트워크 사용을 중단하고 운영체제 보안 검사와 계정 활동을 확인하세요. 자세한 판단 순서는 Windows 파일 확장자를 표시해야 하는 이유와 Chrome 다운로드 경고 판단 기준에서 확인할 수 있습니다.

    공식 자료와 기준

    • Windows의 일반적인 파일명 확장자와 표시 방법 (Microsoft 공식 자료)
    • 사용자 동의 없이 설치될 수 있는 앱 보호 (Microsoft 공식 자료)
    • Chrome의 위험한 다운로드 차단 안내 (Google Chrome 공식 자료)
