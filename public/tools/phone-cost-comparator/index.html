휴대폰 총비용 비교기 · 자급제와 통신사 견적 비교

월 납부액이 아니라 같은 기간의 전체 부담을 비교하세요. 두 견적의 기기 원금과 통신료를 나누어 입력하면 할인 때문에 놓치기 쉬운 비용을 확인할 수 있습니다.

서버 전송·입력값 저장·광고 없음 · 2026-09-26 공개

두 견적 입력하기

모든 금액은 원 단위, 세금 포함 실제 부담액으로 입력하세요. 견적 A·B는 자급제·통신사에 고정되어 있지 않습니다. 값이 바뀌면 기존 결과는 숨겨집니다.

1~60개월. 양쪽 모두 같은 기간으로 계산합니다.

견적 A

선납금 + 남은 원금. 기기 할인은 반영하고 이자는 아래에 별도 입력합니다.

기기 할부·부가서비스를 뺀 월 통신료입니다.

초기 구간이 없으면 0. 비교 기간보다 길게 입력할 수 없습니다.

나머지 기간의 요금입니다. 한 가지 요금만 쓰면 여기에 입력하세요.

전체 기간 동안 매달 같은 금액인 항목만 입력합니다.

이자, 유심, 기간이 다른 부가서비스 등의 합계. 위와 중복 계산하지 마세요.

기기값에 이미 보상판매를 반영했다면 0으로 둡니다.

자동 추천·현재 판매가 조회가 아닙니다. 입력한 가정으로 계산한 결과이며 실제 청구액이나 계약조건을 보장하지 않습니다.

어떻게 계산하나요?

순비용 = 기기 원금 전체 + 초기 통신료 × 초기 개월 + 이후 통신료 × 남은 개월 + 월 부가요금 × 전체 개월 + 일회 비용·이자 − 기존 폰 판매액

할부 원금 전액을 넣으므로, 비교 기간 뒤에 남는 할부 원금을 비용에서 숨기지 않습니다. 이는 현금흐름 계산이 아닙니다. 기기 할부가 포함된 ‘월 납부금’을 월 통신료에도 넣으면 기기값이 두 번 더해집니다.

기준 예시로 계산을 대조하세요

위 ‘가상 예시’ 버튼을 누르면 24개월 동안 A의 판매액 차감 전 합계는 2,590,000원, 순비용은 2,190,000원입니다. B의 합계는 3,340,000원, 순비용은 2,940,000원으로 차이는 750,000원입니다. 예시의 세부 조건과 직접 계산 과정을 공개했습니다. 현재 통신사 상품이나 실제 고객의 견적이 아닙니다.

다음 조건은 별도로 확인하세요

  • 기기 반환형·렌탈 상품과 일반 소유 구매는 그대로 비교하지 마세요. 반환금·인수금 등 계약구조가 다릅니다.
  • 중고폰을 판매하지 않거나 금액이 불확실하면 판매 예상액을 0으로 바꿔 결과를 비교하세요.
  • 실적 조건부 카드 할인·가족 결합·중도 해지 반환금은 자동 반영하지 않습니다. 확정된 조건만 입력하고 지급·유지 조건을 따로 확인하세요.
  • 요금이 세 번 이상 바뀌면 기간별 총액을 먼저 구해야 합니다. 전체 기간의 월평균을 임의로 추측해 넣지 마세요.
  • 현재 폰의 남은 할부처럼 양쪽에 공통으로 발생하는 금액은 같은 방식으로 반영하거나 별도로 기록하세요.
