Read the assumptions first

This model is for allocating a new full copy. If the destination already holds the same archive, this is not an incremental-backup or cleanup calculation.

D = current + growth × months + versions
Budget = D ÷ (1 − reserve / 100)

Reserve is part of the final budget. For the worked example, 198 GB of data ÷ 0.8 gives 247.5 GB. A 200 GB free-space reading leaves a 47.5 GB gap.

It does not estimate compression, deduplication, formatted capacity or changing retention policies. Check actual free space rather than the product’s advertised capacity.

Reading a GiB value?

1 GiB = 1,073,741,824 bytes; 1 GB = 1,000,000,000 bytes. Results display up to two decimals; calculations use unrounded numbers.

Use the estimate to ask a better question

If the budget exceeds free space, investigate the destination and retention policy. Do not delete the only original to make a number turn positive. Map independent copies first.
