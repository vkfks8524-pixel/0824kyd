    결과를 어떻게 읽나요?

    ‘자가 확인 2/6’은 여섯 항목 중 두 항목을 사용자가 표시했다는 뜻입니다. 백업 성공률 33%나 사진 두 개만 저장됐다는 뜻이 아닙니다. 남은 확인은 계정→업로드→원본→동영상→폴더→독립 사본 순서로 제시합니다. 앞의 조건이 불확실하면 삭제·초기화보다 확인이 먼저입니다.

    설명용 예: 계정과 업로드 상태만 확인했다면 사진 원본, 동영상, 카메라 외 폴더, 독립 사본이 남습니다. 이미 만든 결과에서 표시를 해제하면 남은 목록을 즉시 다시 계산합니다. 초기화 버튼은 체크를 해제할 뿐 기기나 사진을 지우지 않습니다.

    서비스별 삭제 동작을 마지막에 다시 확인하세요

    • iCloud 사진의 동기화된 항목을 삭제하는 것과 별도 저장장치에 사본을 두는 것은 다릅니다.
    • Android Google 포토의 기기 공간 확보는 일반 사진 삭제와 다른 기능입니다.
    • 기기 교체는 사진뿐 아니라 앱·계정·회선 이전 확인도 필요합니다.
