백업

폴더 비교 (백업 누락 찾기)

원본과 백업 폴더를 비교해 빠지거나 내용이 달라진 파일을 찾습니다.

비교 방법

두 폴더를 선택해 주세요.

비교 결과

선택한 파일은 이 화면 안에서만 읽으며 서버로 전송되지 않습니다.

두 방법의 차이

빠른 비교는 경로와 크기만 봅니다. 정밀 비교는 내용을 모두 읽고, 다른 위치로 옮긴 파일도 찾습니다. 여섯 파일 시험에서 빠른 비교는 내용이 바뀐 파일 하나를 같다고 보았고, 정밀 비교는 구분했습니다.

정확하게 고르는 법

  • 두 폴더는 같은 단계의 폴더를 고릅니다. 원본에서 "사진"을 골랐다면 백업에서도 "사진"을 고르세요.
  • 폴더 이름 자체는 달라도 됩니다. 그 아래 경로부터 비교합니다.
  • Thumbs.db, desktop.ini, .DS_Store 같은 시스템 파일은 제외합니다.

알아둘 점

  • 파일을 복사하거나 지우지 않습니다. 목록만 만듭니다.
  • 원본이 이미 깨졌다면 깨진 사본도 같은 파일로 나옵니다.
  • 클라우드에만 있는 파일은 선택할 때 내려받아질 수 있습니다.

함께 읽기

  • 외장하드 백업에서 빠진 사진 찾기: 파일 개수가 같아도 안심할 수 없는 이유
  • 라이브 포토 백업: 사진만 남고 움직임이 사라지는 문제 막기
