중복 사진 정리: 완전히 같은 파일과 비슷한 사진은 다르다

이름이 달라도 같은 파일이 있고, 같아 보여도 다른 파일이 있습니다. 파일 10개로 시험하고 안전하게 정리하는 순서를 정리했습니다.

작성·확인 2026년 11월 24일 · KYD · 6분 읽기

핵심 요약
  • 완전히 같은 파일은 이름이 달라도 하나만 남겨도 내용이 사라지지 않습니다.
  • 위치정보를 지우거나 다시 저장한 사진은 같아 보여도 다른 파일입니다.
  • 연속 촬영 사진은 중복이 아니라 선택의 문제입니다.

중복에는 세 종류가 있다

종류예자동 정리해도 되나
완전히 같은 파일사진을 두 번 내려받아 (1)이 붙음하나를 남기면 내용은 보존됨
같은 장면, 다른 파일메신저로 받은 축소본, 위치정보를 지운 사본원본이 어느 쪽인지 확인 필요
비슷한 사진연속 촬영, 같은 장소에서 다시 찍음직접 골라야 함

"비슷한 사진 찾기" 앱은 두 번째와 세 번째까지 찾아 주지만, 원본과 축소본 중 무엇을 남길지 잘못 고를 수 있습니다. 먼저 첫 번째 종류만 확실하게 정리하는 편이 안전합니다.

파일 10개로 확인한 결과

일부러 만든 파일 10개를 중복 파일 찾기와 같은 코드로 검사했습니다.

파일관계판정
reference.svg / identical-copy.svg이름만 다름중복
photo.jpg / photo (1).jpg이름만 다름중복
metadata-change.svg그림은 같고 정보 한 글자만 다름중복 아님
visible-change.svg크기는 같고 색이 다름중복 아님
truncated.svg앞부분만 남은 파일중복 아님
photo_정보삭제.jpgphoto.jpg에서 위치정보를 지운 사본중복 아님
빈 파일 2개0바이트검사에서 제외

중복 묶음은 2개, 여분은 2개였습니다. 크기가 같다고 중복으로 보지 않았고, 이름이 달라도 놓치지 않았습니다. 0바이트 파일은 내용이 없어 모두 "같은 파일"이 되므로 따로 셉니다.

도구가 판단하는 방법

  1. 파일 크기가 같은 것끼리 묶습니다. 크기가 다르면 내용이 같을 수 없습니다.
  2. 묶음 안에서 4MB씩 읽어 모든 바이트를 비교합니다.
  3. 한 바이트라도 다르면 다른 파일로 나눕니다.

파일 이름, 촬영 날짜, 썸네일은 판단에 쓰지 않습니다. 전체를 한꺼번에 메모리에 올리지 않으므로 큰 동영상도 비교할 수 있지만, 같은 크기의 큰 파일이 많으면 시간이 걸립니다.

안전하게 지우는 순서

  1. 정리하려는 폴더를 다른 곳에 한 번 복사해 둡니다.
  2. 도구로 목록을 만들고 CSV로 저장합니다.
  3. 묶음마다 남길 파일 하나를 정합니다. 연도별·행사별 폴더처럼 나중에 찾기 쉬운 위치를 남기면 좋습니다.
  4. 남길 파일을 직접 열어 봅니다.
  5. 나머지를 휴지통으로 옮깁니다. 바로 완전 삭제하지 않습니다.
  6. 며칠 동안 앨범이나 문서에서 찾을 수 없는 사진이 없는지 확인한 뒤 휴지통을 비웁니다.

특히 조심할 것

  • 프로그램이 관리하는 사진 보관함 폴더 안의 파일을 직접 지우지 마세요. 앱의 목록과 실제 파일이 어긋납니다.
  • 백업 폴더와 원본 폴더를 함께 검사하면 정상적인 백업이 모두 중복으로 나옵니다. 백업은 지울 중복이 아닙니다.
  • 아이폰 라이브 포토의 사진과 짧은 동영상은 서로 다른 파일이며 둘 다 필요합니다.
  • 구글 포토 컴퓨터 백업은 공식 도움말에 따르면 이미 백업된 콘텐츠를 다시 업로드하지 않습니다. 클라우드에 이미 있다는 이유로 PC 원본을 중복이라고 판단하지는 마세요.

자주 묻는 질문

도구가 왜 바로 지워 주지 않나요?

브라우저는 고른 파일을 읽을 수만 있고, 실수로 지운 사진은 되돌리기 어렵기 때문입니다. 목록을 만들고 사람이 남길 파일을 고르는 방식이 더 안전하다고 판단했습니다.

남길 파일은 어떻게 고르나요?

내용은 모두 같으므로 위치로 고릅니다. "다운로드"나 "새 폴더"보다 날짜와 행사가 적힌 폴더를 남기고, 이름에 (1), 복사본이 붙은 쪽을 정리하는 기준이 무난합니다. 다른 문서나 앨범이 연결한 파일이라면 그 경로를 남기세요.

비슷한 사진까지 줄이고 싶습니다

완전히 같은 파일을 먼저 정리한 뒤, 행사별로 화면을 넘기며 대표 사진을 고르세요. 눈 감은 사진이나 흔들린 사진은 사람이 판단하는 편이 빠르고 정확합니다.
