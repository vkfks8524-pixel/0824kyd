Show file extensions in Windows—and know what they cannot prove

By KYD Editorial · First published 2026-07-12 · Last editorial review 2026-10-05

English edition adapted on 2026-10-05. The original source-check date is retained below; this is not a fresh product or match investigation.

A document-looking filename may hide another ending. Showing extensions helps you read the complete name without opening the file, but it is not a file-format or malware test.

Enable the display and check the result

In Windows 11 File Explorer, use View → Show → File name extensions. In the Windows 10 ribbon interface, use the View tab’s File name extensions checkbox. These instructions are based on Microsoft documentation; this article does not present original Windows screenshots.

  1. Open a folder with a document whose source you know.
  2. Enable extensions and confirm that the ending such as .pdf or .docx is visible.
  3. Widen the Name column if the ending is truncated, or select the file once to inspect its full name. Do not double-click just to check.
  4. Compare the ending, sender and file type you actually expected.

The setting changes display, not file contents. Special formats such as shortcuts may also require checking Properties and the target.

Extension, icon, contents and signature are different

An extension helps the operating system select an app. The icon is also influenced by associations and settings. Both can change without converting the underlying data, so neither proves the real format. A signature can provide publisher information, but is not permission to run any file. Many documents have no signature tab; its absence alone does not prove malware.

Older .doc, .xls and .ppt formats can contain macros too. Do not ignore a warning solely because the filename does not end in .docm.

Practice without uploading files

Enter the examples in the filename and extension checker. Compare notice.pdf.exe with minutes.final.docx. The tool reads strings only; it does not test Explorer or detect malware. The tool verification notes publish its test scope.

If you renamed or ran the file

If you changed an extension on your own file and know its original name, restore it. Do not guess different extensions on an unknown file to make it open. Obtain the original from the sender or convert it using the producing app’s export function. Downloading is different from executing or installing. If unwanted apps appeared after execution, use the download-warning response guide or your organization’s support process, not a name-only check.
