Starting with a password manager without locking yourself out

By KYD Editorial · First published 2026-07-12 · Last editorial review 2026-10-05

English edition adapted on 2026-10-05. The original source-check date is retained below; this is not a fresh product or match investigation.

A password manager makes different passwords for different sites easier to maintain. Start with the vault’s protection and recovery path before moving every account into it.

Understand what changes

Instead of remembering every site password, you protect a vault and use it to store or fill separate credentials. This reduces the practical pressure to reuse one password. It is not a tool that eliminates every risk, and generated passwords can still be exposed through phishing, device compromise or other failures.

Protect the main password and recovery path

Where the manager uses a master password, choose a long, unique passphrase that you do not use on another website. Avoid birthdays, phone numbers and account names. Review the actual manager’s recovery procedure before relying on it. A securely stored offline record may be useful; do not keep the only recovery copy inside the account that could become inaccessible.

Move important accounts gradually

Email and cloud accounts often support resets for other services, so start there, then work through financial, shopping and frequently used work accounts. Generate and save a new password, sign out and verify that you can sign in again. Do not change every password in one sitting without checking that the manager saved each one correctly.

Use two-step verification too

Protect the manager itself and important email accounts with a suitable second factor where supported. Keep recovery codes separately and verify access to a backup method. Losing the phone should not mean losing the only route back to every account.

Do not overrule missing autofill blindly

If the manager does not recognize a login page, inspect the complete address. A different domain may be a phishing warning, although missing autofill alone does not prove fraud. Do not manually paste credentials merely because an unexpected page asks you to.

Avoid two conflicting credential lists

If you use both browser storage and a dedicated manager, decide which one is the primary record. Duplicate or outdated entries can make it difficult to know which password is current. Review old entries carefully rather than deleting access information you have not verified elsewhere.

Rehearse the recovery plan safely

Read the emergency instructions and locate the recovery codes, registered email and security key before a real lockout. Check that a second method is actually available if a phone is lost. This is preparation, not a reason to deliberately lock or erase a working account.
