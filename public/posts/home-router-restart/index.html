Slow home internet: isolate the problem before restarting the router

By KYD Editorial · First published 2026-07-12 · Last editorial review 2026-10-05

English edition adapted on 2026-10-05. The original source-check date is retained below; this is not a fresh product or match investigation.

Restarting can help, but first find out whether the problem affects one device, one room, one website or the whole connection. That comparison makes the next action more useful.

Compare one thing at a time

Open the same site on another device, then try another site. If only a laptop is slow, inspect its Wi-Fi connection, browser and background updates. If one site is slow everywhere, the site itself may be involved. If all devices struggle, compare the router, modem and provider connection rather than assuming one cause.

ObservationNext comparisonAvoid concluding
Only one device is slowIts Wi-Fi, apps and updatesThat the router has failed
Every device is slowWired access, equipment lights and provider noticesThat a more expensive plan is necessarily needed
A restart helps only brieflyHeat, firmware and connection historyThat repeated resets solve the underlying cause

Separate Wi-Fi coverage from the internet connection

Try the same device closer to the router. Walls, metal furniture and nearby interference can affect wireless coverage. Where available, compare a wired connection. Turning off Wi-Fi and trying mobile data provides another route, but remember that it uses a different network and may incur charges. Record the conditions rather than treating these comparisons as definitive diagnoses.

Look for busy periods

Large downloads, game updates, cloud backups and simultaneous video use can compete for the connection. Note whether the slowdown happens at a particular time or with particular tasks. Inspect active work before assuming hardware failure.

Restart is not factory reset

Follow the equipment manufacturer or provider’s restart procedure. The original guide described switching power off, waiting roughly ten seconds and restarting; separate modem-and-router setups may require the modem to stabilize first. Record the light pattern before and after. A factory reset erases configuration and is a different operation: do not begin with it.

If the problem persists

Review placement and official firmware instructions. Preserve the Wi-Fi name, access details and required connection configuration before making changes. An older router serving many devices may be a limiting factor, but compare wired performance and provider status before purchasing replacement equipment or changing the plan.

Make the support report specific

Provide the affected devices, whether wired access differs, the time pattern, light status and actions already tried. Change one variable, then observe the result. If you change power, position, cabling and settings together, you lose the evidence of which action helped.
