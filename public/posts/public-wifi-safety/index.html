Public Wi-Fi: check the network and the destination separately

By KYD Editorial · First published 2026-07-12 · Last editorial review 2026-10-05

English edition adapted on 2026-10-05. The original source-check date is retained below; this is not a fresh product or match investigation.

Public Wi-Fi is convenient, and HTTPS protects much modern web traffic. Still check the network you join and the website you use: an encrypted connection to an impostor site is not a trusted transaction.

Verify the exact hotspot name

Compare the network name with the venue’s official notice or ask staff. Similar names can belong to different access points. A familiar-looking SSID is not proof of who operates it. If you cannot establish which network is intended, use another connection.

Review auto-join and sharing

Disable automatic connection to public networks you do not need regularly, or forget them after use. On a Windows laptop, use the appropriate public-network profile and inspect network discovery, file sharing and printer sharing. Do not apply Windows menu instructions to every phone platform; controls differ by device.

Task or observationPractical choiceAdditional check
General search or news readingUse the intended site over HTTPSKeep unnecessary sharing and auto-join off
Banking, payment or important account changesPrefer mobile data or another trusted route where practicalVerify the destination and avoid urgent unexpected prompts
Several similar hotspot namesConfirm the exact SSID with the venueDo not select solely by signal strength

Understand what HTTPS does

HTTPS encrypts communication with the selected site and reduces interception risks. It does not make a fake login page genuine, make downloaded software trustworthy or prevent every device problem. Continue checking the domain and browser warnings even on a private network.

Choose the connection to fit the task

For sensitive work, consider using mobile data, a personal hotspot or a connection you control. A trusted VPN may be part of an organization’s policy, but it is not a substitute for verifying websites or files. Do not install an unfamiliar VPN merely because a hotspot advertises it.

Clean up after the session

Disconnect when finished and review saved networks. If you used a shared computer, do not save credentials and sign out of websites and the browser account as appropriate. Public networking and public-device use are separate risks; changing the network does not remove a session from someone else’s computer.

If something seems wrong

Record the actual action and account involved. If you entered a password on an unexpected page, review that account from a trusted device, starting with important email and recovery-linked services. Do not conclude that every account was compromised merely because you used public Wi-Fi.
