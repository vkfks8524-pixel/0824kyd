Privacy & local processing

Tool inputs stay in the page. Visiting a website still creates technical requests. These are different things.

What the tools read

The checklist reads selected boxes. The planner reads numbers you enter. The copy checker reads the contents of two files only after you choose them and start the comparison. Its demo uses built-in text fixtures. It does not upload file contents, names, fingerprints or results to KYD.

The tool code does not use cookies, local storage, browser databases or server-side accounts to retain your inputs. Reloading clears application state; a browser may restore some form values under its own settings. Optional text downloads are created in your browser and saved where you choose. Exported comparison summaries omit filenames but fingerprints may still be sensitive: keep reports private.

File selection and page security

Tool pages use a content security policy that prohibits outgoing script connections and third-party scripts. They have no advertising script. A file picker backed by a cloud service may download the chosen file through the browser or operating system before this page reads it; this is not an upload by KYD. Browser extensions and software outside this page are outside KYD’s control.

Hosting and analytics

Cloudflare provides hosting and security and may process IP addresses, request times, URLs, browser information and referrers. Cloudflare Web Analytics may collect page-level performance and visit information on pages where its beacon is served; tool-page script restrictions block that third-party beacon. Local-only inputs do not mean the whole website makes no network requests. See Cloudflare’s privacy policy.

Advertising

The site retains its AdSense publisher identification and ads.txt record. The focused edition does not load AdSense advertising JavaScript or serve ad units. Publisher identification is not evidence of approval. Before advertising is enabled, the policy and consent implementation must be reviewed for the regions served.

When Google advertising is used, Google and its partners may use cookies or similar technologies for advertising, measurement and fraud prevention, and personalized advertising may use previous visits. See Google’s advertising data information and My Ad Center. This notice is not itself a consent platform.

External services and contact

The site has no registration, comments or private contact form. Corrections go through public GitHub issues. GitHub and linked providers apply their own policies; posting there may make your information public. Do not submit private information. Technical provider logs may be retained under those providers’ policies; KYD’s tool code does not maintain a user-input database.

Changes

Material changes to input handling, advertising or analytics should be reflected here and in the change record. Report a privacy-description error without disclosing sensitive data.
